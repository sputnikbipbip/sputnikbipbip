## 👨‍💻 About Me

I'm a **Backend Software Engineer with 3+ years of professional experience building production software with C# and .NET**.

I spent nearly three years at **Bizay**, a global e-commerce platform, working on backend services, microservices, external integrations and production systems at scale.

Since then, I've been working independently on software projects, giving me experience not only in development but also in **architecture, deployment, infrastructure and solving problems end-to-end**.

My main interests are:

- 🧩 Backend development with **C# / .NET**
- ⚙️ **Distributed systems & microservices**
- 🔌 REST APIs and third-party integrations
- 🗄️ SQL and NoSQL databases
- 🐳 Docker & cloud infrastructure
- 📊 Observability and production debugging
- 🤖 **AI agents, automation and MCP**
- 🏗️ System design and software architecture

I'm currently expanding my knowledge of **Python, LLMs, AI agents and MCP**, while continuing to build on my .NET and distributed-systems background.
